   ticket ID/blob, execution ID, exact control/product admission, Git common

   generation check and exact remote observation.

   The implementation records exclusive creation/operation receipts, pinned
   filesystem and reflog witnesses and a worktree Git-admin generation marker.

   identity, symlinks, locks, cleanliness and submodules. Local worktree/ref
   recreation at the same SHA is rejected. Remote ref continuity remains
   explicitly **unknown**, which the canonical ticket expressly permits.
4. **Lifecycle and crash recovery — PASS.** Binding checks cover worker
   handoff and independently receipted worker-group retirement, checkpoint

6. **Non-interference/boundaries — PASS.** No operator reset CLI, general VCS

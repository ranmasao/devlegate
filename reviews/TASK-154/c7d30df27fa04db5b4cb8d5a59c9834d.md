Build `HEAD[-N]` from **actual task code checkpoints**, not Git parent count, and handle failed/zero-delta sessions, rebase/squash, retained cross-base history and unrelated target advances without invented checkpoint IDs.
2. **Honest cost/output controls:** `ImmutableExplorer._tree` bounds an individual `ls-tree` read to 2 MiB and `_git` has a deadline; however `changes()` emits up to 30 paths of up to 4096 UTF-8 bytes each with no serialized response cap and no per-execution metering. `diff()` refuses any text file exceeding 32 KiB, even if a small change could be computed cheaply, contrary to the ticket's large-file/small-diff requirement.
